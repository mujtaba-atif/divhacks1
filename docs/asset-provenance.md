# Demonstration evidence assets

`public/evidence-before.png` and `public/evidence-after.png` were generated with
the built-in image generation tool on 2026-09-26. They are synthetic demo assets,
not photographs submitted by a tenant. Both images visibly say `DEMO SAMPLE`.

Prompt used for each image (temperature substituted with 54 or 72):

> Create one photorealistic square demonstration asset for a housing repair
> software prototype. A small white digital room thermometer on a clean apartment
> windowsill beside the edge of a cast-iron radiator, daylight, clear sharp
> close-up, no people, readable LCD display showing exactly "[temperature] F".
> The thermometer is centered and occupies 50 percent of the frame. Neutral white
> walls, very subtle green houseplant edge, natural soft lighting. Add a small but
> clearly readable caption at the bottom left saying exactly "DEMO SAMPLE". This
> is a synthetic example, not real tenant evidence. No other text, no brand, no UI
> chrome. 1024 by 1024 composition.

The actual generation prompt used the degree symbol between the temperature and
F. No image editing or external stock assets were used.
